## 1. Platform Definition

## 5. Domain Boundaries

### Backend (Laravel 11 REST API)

```
|-- Identity/Auth   -> users, roles, user_roles
|-- Content         -> categories, articles, article_versions,
|                      tags, article_tags, bookmarks, article_attachments
|-- Learning        -> learning_roadmaps, roadmap_items,
|                      learning_progress, roadmap_item_prerequisites
|-- AI Companion    -> conversations, messages, user_memories  [TBD owner]
+-- Payment         -> plans, subscriptions, payments, webhook_events  [TBD owner]
```

### Frontend (Next.js / React — `frontend/`)

```
frontend/src/
|-- app/                 App Router pages (layout, home, 404)
|   |-- (auth)/login/    Login page (route group, no URL segment)
|   +-- courses/         Courses listing + [id] dynamic detail
|-- components/          Reusable UI and layout components
|-- lib/api.ts           Centralized API client for Laravel REST API
|-- hooks/               Custom React hooks
|-- types/               TypeScript type definitions
+-- styles/              Shared CSS modules / design tokens
```

---

## 6. Authentication & Authorization Boundary

- Auth package/mechanism: **not implemented or tracked**; select only through approved task/ADR as needed
- RBAC target: Laravel Policy + Gate; 3 roles: `admin`, `contributor`, `user`
- Guest (unauthenticated): read-only access to published content; no DB role
- PG RLS: not implemented; documented as future task
- Supabase Auth, Storage, Edge Functions, and direct browser database access are not used.

---

## 7. API Boundary

- All client communication goes through Laravel REST API only
- No direct DB access from clients
- Contract: `docs/API.md`
- Frontend uses contract as decoupling boundary (mock-first until API ready)
- AI service boundary: defined when AI phase begins

---

## 8. Dependency Direction

```
Frontend --> Laravel API --> Supabase PostgreSQL (production)
                         --> Docker PostgreSQL (local/test)
                         --> (future) AI Service
                         --> (future) S3
```

Frontend depends on API contract only. AI service is independent from Laravel internals.
