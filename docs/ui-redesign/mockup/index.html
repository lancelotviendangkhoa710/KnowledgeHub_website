Hệ thống phân tán: Những đánh đổi cơ bản

TTeam Test Contributor Cập nhật 13/11/2026 Phiên bản 3, xem lịch sử

Mục tiêu

Hiểu các đánh đổi cốt lõi của hệ thống phân tán (CAP, nhất quán và sẵn sàng) và cách thuật toán đồng thuận Raft giữ dữ liệu nhất quán.

1. Bối cảnh: vì sao cần thuật toán đồng thuận

Trong hệ thống phân tán, nhiều máy chủ phải thống nhất cùng một chuỗi thay đổi dữ liệu dù có máy bị sập hoặc mạng bị chia cắt. Raft giải bài toán này bằng cách bầu ra một leader duy nhất, leader nhận lệnh và nhân bản log sang các follower.

Designing for Understandability: The Raft Consensus Algorithm, Diego OngaroMở trên YouTube

2. Ba trạng thái của một node

  • Follower: nhận log từ leader, trả lời heartbeat.
  • Candidate: hết thời gian chờ heartbeat thì tăng term và xin phiếu bầu.
  • Leader: được đa số phiếu, gửi AppendEntries định kỳ.
typescript
type Role = 'follower' | 'candidate' | 'leader';

interface ConsensusNode {
  id: string;
  role: Role;
  currentTerm: number;
  votedFor: string | null;
  log: { term: number; command: string }[];
  commitIndex: number;
}

3. Bất biến cần giữ

Ghi nhớMột entry chỉ được coi là committed khi đã được ghi trên đa số node. Mỗi term có nhiều nhất một leader.

4. Bài tập

  1. Vẽ lại diễn biến khi leader bị mất kết nối với 2/5 node.
  2. Giải thích vì sao follower từ chối AppendEntries có term nhỏ hơn currentTerm của nó.

Mục lục

1. Vì sao cần thuật toán đồng thuận 2. Ba trạng thái của một node 3. Bất biến cần giữ 4. Bài tập

Bạn có thể hỗ trợ mình lộ trình để trở thành data engineer không?

Chắc chắn rồi. Dưới đây là lộ trình tham khảo để trở thành Data Engineer, chia theo giai đoạn.

1. Nền tảng cơ bản, 1 đến 2 tháng

  • Lập trình: Python, thêm SQL thành thạo
  • Cơ sở dữ liệu: mô hình quan hệ, chuẩn hóa, index, join
  • Linux và Git: dòng lệnh cơ bản, quản lý phiên bản

2. Kỹ năng cốt lõi, 2 đến 3 tháng

  • SQL nâng cao: window functions, CTE, tối ưu query
  • ETL và ELT: khái niệm pipeline, batch và streaming
  • Định dạng dữ liệu: CSV, JSON, Parquet, Avro

3. Công cụ và hạ tầng, 2 đến 3 tháng

  • Orchestration: Apache Airflow
  • Xử lý dữ liệu lớn: Apache Spark
  • Container và CI/CD: Docker, GitHub Actions cơ bản
